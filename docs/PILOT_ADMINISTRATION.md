# Pilot administration

The administrator page is for Puli Consulting pilot administrators and superusers. Writers should use email sign-in instead.

## Visitor access queue

- **Pending:** the visitor has requested access and awaits review.
- **Approve and email:** creates an email-bound invitation for two completed sessions, sets a 14-day invitation expiry, and emails the code through the configured company mailbox.
- **Decline:** closes the request without creating an invitation.

Review the visitor's stated purpose before acting. Approval sends an external email and should be used only for an intended pilot participant.

## Create an invitation manually

Use **Invite a pilot user** when Puli Consulting has already selected the recipient and no public request is needed.

1. Enter the recipient's exact email address.
2. Choose the invitation expiry.
3. Leave email delivery selected when the configured company mailbox should send the invitation.
4. Select **Create two-session invitation**.

The full code appears only at creation time or in the recipient's email. **Copy code** copies only the code. **Copy registration details** copies the code and registration link. The interface displays confirmation after a successful copy.

## Invitation status

- **Active:** not yet registered and still within its expiry period.
- **Redeemed:** used to register the email-bound account.
- **Expired:** no longer valid.
- **Revoked:** cancelled by an administrator before use.

Stored invitation records show only the final six code characters. The full code cannot be recovered from the database.

## Participation and progress

The operations dashboard shows privacy-safe account and progress aggregates, including completed sessions, remaining credits, pace, and assessment-score change. **Export CSV** downloads those operational measures without writing content.

Completed writing and AI feedback remain encrypted. Do not publish screenshots containing real email addresses, invitation codes, sign-in links, or participant writing.
