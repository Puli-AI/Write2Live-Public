# Getting started

Write2Live is currently available by invitation during its private pilot.

1. Open [write2live.puli-consulting.com](https://write2live.puli-consulting.com).
2. Enter the access information supplied by Puli Consulting.
3. Choose a writing direction or discover current ideas.
4. Set a duration and momentum mode.
5. Write until the timer ends, then finish or add a short extension.
6. Request refinement, assessment, or coaching only when you want AI assistance.
7. Copy or export the writing and results you want to keep.

The current pilot keeps an unfinished draft in the browser so it can be resumed on the same device. Account-based history and progress tracking are planned for the v0.8 beta.
